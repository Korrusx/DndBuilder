# Конструктор персонажей 5e

Мобильное приложение для создания персонажей пятой редакции (5e) и игры ими за столом. Работает без интернета,
всё считает само: модификаторы, спасброски, навыки, КЗ, хиты, атаки, ячейки заклинаний.

Интерфейс на русском (можно переключить на английский). Два справочника: правила 2024 года (SRD 5.2)
и 2014 года (SRD 5.1).

## Возможности

- Мастер создания в 6 шагов: класс, предыстория и вид, характеристики (стандартный набор, покупка очков,
  броски 4к6), навыки и владения, снаряжение и заклинания, проверка.
- Режим игры: хиты и временные хиты, кости хитов, состояния, истощение, короткий и долгий отдых.
- Броски навыков и атак с преимуществом и помехой.
- Заклинания: СЛ, бонус атаки, ячейки по кругам, урон по кругу ячейки.
- Повышение уровня и мультикласс.
- Экспорт листа персонажа в PDF (A4, 2 страницы).
- Экспорт и импорт персонажа файлом `.dnd.json`.

## Запуск

Нужно:
- [Node.js](https://nodejs.org/) 22.18 или новее;
- приложение **Expo Go** на телефоне (Android или iOS).

```bash
npm install
npx expo start
```

В терминале появится QR-код. Отсканируйте его в Expo Go (на iOS — камерой). Телефон и компьютер должны быть
в одной сети Wi-Fi; если не получается, запустите `npx expo start --tunnel`.

### Другие команды

```bash
npm test             # тесты логики правил (Jest)
npm run typecheck    # проверка типов TypeScript
```

Сборка APK через EAS: `npx eas build -p android --profile preview` (нужен аккаунт Expo).

## Справочник

Приложение не ходит в сеть: справочник собран заранее в `assets/content/content.json` (2024)
и `assets/content/content-2014.json` (2014). Пересобирать его нужно, только если меняете данные или перевод.

Данные берутся из [dnd5eapi](https://www.dnd5eapi.co/), перевод лежит в CSV-таблицах
`data-pipeline/translations*/`. Как скачать данные, собрать справочник и вести перевод — в
[`data-pipeline/README.md`](data-pipeline/README.md).

## Устройство проекта

Expo (React Native) + TypeScript, expo-router, expo-sqlite, i18next. Код организован по
Feature-Sliced Design:

```
app/             маршруты expo-router
src/shared/      тема, справочник, база, i18n, UI-кит
src/entities/    персонаж: правила 5e (чистые функции с тестами), работа с базой
src/features/    действия пользователя: создание, урон и лечение, отдых, PDF…
src/widgets/     составные блоки экранов
src/pages/       экраны
data-pipeline/   скрипты подготовки справочника
```

Правила слоёв проверяет тест `src/architecture.test.ts`.

Документация: [`docs/status.md`](docs/status.md) — текущее состояние и упрощения,
[`docs/multiclass.md`](docs/multiclass.md) — мультикласс,
[`docs/edition-2014.md`](docs/edition-2014.md) — редакция 2014.
