# ТЗ: итоговый экран повышения уровня — «Карта героя»

Прочитай CLAUDE.md, документацию `docs/features/level-up.md` и спецификацию `design/level-up/hero-card-spec.md`. Спецификация — источник правды по внешнему виду: размеры, цвета, шрифты, тайминги. Картинки `u5-itog.png`, `u5b-storis.png`, `u5v-stili-karty.png` показывают результат, исходники в `design/level-up/source/` нужны, если чего-то нет в спецификации.

Задача: заменить текущий итоговый экран повышения уровня (У5) и сделать его **один в один по макету**: карта героя в трёх стилях, анимация появления, смена стиля, наклон, картинки для поста и сторис.

Работай по шагам: после каждого шага запускай тесты, коротко отчитывайся и делай коммит. Не переходи к следующему шагу, пока текущий не проверен.

## Шаг 0. Проверка и план (код не пиши)

1. Найди текущий итоговый экран повышения уровня и то, откуда он берёт данные (колода, `keyNumbersPreview`, событие хроники).
2. Проверь, работает ли в нашей сборке (Expo Go и EAS) `@shopify/react-native-skia`. Если работает, проверь, захватывает ли `react-native-view-shot` холст Skia на Android. Если нет — предложи: снимок через `makeImageSnapshot` Skia или запасной вариант без Skia (спецификация, раздел 8).
3. Проверь, есть ли в проекте шрифты Alegreya SC и IBM Plex Sans Condensed (их использует PDF-лист). Как их подключить к экранам.
4. Проверь, хранится ли у персонажа род (для заголовка сторис). Если нет — используем нейтральный заголовок, ничего не добавляй.
5. Пришли план: файлы, компоненты, где хранить `heroCardStyle`, как будешь рендерить картинки для «Поделиться». Жди моего «ок».

## Шаг 1. Темы и правила содержимого

- Файл тем (например, `src/ui/heroCard/themes.ts`): три стиля, **все** токены из спецификации, раздел 3. В компонентах карты не должно быть ни одного цвета напрямую.
- Чистые функции с тестами (раздел 7): `pickCardStats`, `cardSubtitle`, `cardUnlocked`, `cardNext`, `cardFooter`, `defaultCardStyle`.
- Константа знака бренда `BRAND_MARK` в одном месте.
- Поле персонажа `heroCardStyle` (миграция, если нужна).

## Шаг 2. Компонент карты

- `HeroCard` — компонент только для отображения: получает данные и тему, ничего не считает сам.
- Анатомия и размеры — спецификация, раздел 2. Два размера: полный (экран итога, пост) и компактный (сторис, раздел 9.2).
- Портрет: фото по кругу или буква.
- Подпись для экранного диктора, декоративные слои скрыты.

## Шаг 3. Экран итога

- Раскладка — раздел 1, кнопки стиля — раздел 4.1.
- Анимация появления — раздел 5: один раз, с вибрацией и искрами.
- Смена стиля кнопками и свайпом, поворот карты, переход фона, повтор блика, запоминание — раздел 4.
- Стиль по умолчанию от класса — раздел 4.4.
- «Уменьшение движения» и настройка «Анимации повышения уровня» — раздел 5, последний абзац.

## Шаг 4. Наклон

- `expo-sensors`, `DeviceMotion` — раздел 6: сглаживание, пределы, блик следует за наклоном.
- Только пока экран открыт и приложение активно; пауза во время свайпа; выключен при «уменьшении движения».
- Освобождать подписку на датчик при уходе с экрана.

## Шаг 5. «Поделиться»

- Шторка: «Пост 4:5» и «Сторис 9:16» — раздел 9.
- Невидимый контейнер фиксированного размера → снимок нужной ширины → `expo-sharing`.
- Картинка в текущем стиле, без анимаций, заголовок сторис без рода (если род не хранится).
- Временные файлы удалять после отправки.

## Шаг 6. Тесты

- `pickCardStats`:
  - Ирма 5 → 6 с компетентностью в Восприятии и Акробатике → «ХИТЫ 46 +8», «ВОСПРИЯТИЕ +7 +3», «АКРОБАТИКА +10 +3»;
  - уровень с одним изменением → два оставшихся медальона из КЗ, хитов и атаки с «—»;
  - рост скрытой атаки → значение «4к6», изменение «+1к6».
- `cardSubtitle`: мультикласс → «Полурослик · Плут 5 / Волшебник 1».
- `cardNext`: на 20-м уровне → `null`.
- `cardFooter`: без кампании → только дата `ДД.ММ.ГГГГ`.
- `defaultCardStyle`: волшебник → `night`; плут → `amber`; плут 3 / колдун 5 → `night`; плут 3 / колдун 3 → по первому взятому классу.
- Снимки компонента `HeroCard` во всех трёх стилях (snapshot-тесты): в разметке нет цветов вне темы.
- Экран при «уменьшении движения» сразу в конечном состоянии.
- Выбранный стиль сохраняется и восстанавливается после перезагрузки персонажа.
