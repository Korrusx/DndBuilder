## Исходники (`source/`)

`*.dc.html` — макеты в HTML. Из них берутся точные отступы, размеры шрифтов, радиусы, цвета и тексты.

Как читать:
- разметка внутри `<x-dc>` — сам экран; стили записаны прямо в `style="…"`;
- `{{имя}}` — подстановка значения из функции `renderVals()` в конце файла;
- `<sc-for list="{{список}}" as="элемент">` — повтор блока для каждого элемента списка;
- `<sc-if value="{{условие}}">` — блок показывается, только если условие истинно;
- `<helmet>` — шрифты и общие стили, в том числе `@keyframes` анимаций (`LvlStart.dc.html`, `LvlMagic.dc.html`);
- файл `support.js`, на который ссылаются макеты, не нужен: это служебный файл редактора макетов.

Это макеты, а не код для копирования. Экраны в приложении собираются из компонентов проекта (React Native) с токенами из CLAUDE.md. Имена, числа и тексты на макетах — примеры.
