# Карта героя: спецификация оформления

Точное описание итогового экрана повышения уровня (У5), карты героя в трёх стилях и картинок для «Поделиться». Цель — повторить макет один в один.

Источники правды, по убыванию:
1. Этот файл: размеры, цвета, тайминги, правила содержимого.
2. Картинки `u5-itog.png`, `u5b-storis.png`, `u5v-stili-karty.png` — как должно выглядеть.
3. Исходники `source/LvlDone.dc.html`, `source/LvlStory.dc.html`, `source/LvlThemes.dc.html` — если чего-то нет в этом файле.

Все размеры даны в точках (pt / dp) для экрана шириной 390. На других ширинах карта занимает ширину экрана минус поля по 20 с каждой стороны, но не больше 390 − 40 = 350; внутренние размеры не масштабируются.

## 1. Экран итога (`u5-itog.png`)

Колонка на весь экран, поля: сверху 18 + безопасная зона, по бокам 20, снизу 18 + безопасная зона. Расстояние между блоками 14.

Сверху вниз:
1. **Шапка** по центру, зазор 2:
   - надзаголовок «НОВЫЙ УРОВЕНЬ»: Golos Text 12, межбуквенный интервал 0,18 em, цвет `accentLabel` стиля;
   - заголовок «Путь продолжается» (на 20-м уровне — «Легенда»): Unbounded 600, 20, цвет `#F1ECE2`.
2. Распорка (растягивается, минимум 8).
3. **Карта героя** (раздел 2) с искрами вокруг.
4. Распорка (растягивается, минимум 8).
5. **Нижний блок**, зазор 12:
   - выбор стиля (раздел 4.1);
   - две кнопки в сетке из 2 колонок, зазор 8, высота 56, скругление 16, шрифт Unbounded 600 14:
     - «Поделиться» с иконкой «стрелка вверх из коробки» 18 pt: фон `#F2B14A`, текст `#1A1406`, без рамки;
     - «К листу»: фон `rgba(26,29,34,0.8)`, рамка 1 `#3A3222`, текст `#F1ECE2`;
   - строка «✓ Записано в хронику · сессия 12»: Golos 12, цвет `#7FE0A8`, по центру. Без кампании строки нет.

**Фон экрана:** радиальный градиент с центром (50 %, 38 %), цвета по стилю (раздел 3, `screenBg`): 0 % → 48 % → 80 %, дальше последний цвет. При смене стиля фон плавно переходит за 300 мс.

## 4. Смена стиля

### 4.1 Кнопки стиля
- Ряд из трёх кнопок по центру, зазор 8. Кнопка: высота 36, скругление 18, поля по бокам 14, Golos 13, кружок-образец 12 (линейный градиент 135°: Янтарь `#FFD58A → #8A6A2E`, Ночь `#DCC2FF → #3A2F5C`, Пергамент `#F3EAD3 → #7B2D26`) и подпись, зазор 6.
- Выбранная: рамка 1,5 `#F2B14A`, фон `#2B2416`, текст `#F2B14A`. Остальные: рамка 1 `#2C323B`, фон `#1A1D22`, текст `#C9C3B8`.
- Область нажатия не меньше 44 (`hitSlop` по 4 сверху и снизу).

### 4.2 Свайп по карте
- Горизонтальный свайп по карте переключает стиль: влево — следующий, вправо — предыдущий, без зацикливания. Порог 40 pt или скорость 500 pt/с.
- Вертикальная прокрутка и наклон (раздел 6) свайпу не мешают.

### 4.3 Переход
- Карта поворачивается вокруг вертикальной оси: 0° → 90° за 150 мс (ease-in), в этот момент меняется стиль, затем 90° → 0° за 150 мс (ease-out). Перспектива 1000.
- Фон экрана плавно переходит за 300 мс.
- После перехода блик пробегает ещё раз (раздел 5, 1400 мс).
- Лёгкая вибрация `Haptics.selectionAsync()`.

### 4.4 Запоминание и стиль по умолчанию
- Выбранный стиль хранится у персонажа: `heroCardStyle: 'amber' | 'night' | 'parchment'`.
- Если не выбран: волшебник, колдун, чародей → `night`; остальные → `amber`. При мультиклассе решает класс с наибольшим числом уровней, при равенстве — первый взятый.
- Картинки для «Поделиться» используют текущий стиль.

## 5. Анимация появления

Играет **один раз** при открытии экрана. На макете она зациклена только для показа на холсте: проценты `@keyframes` в макете не являются целевыми таймингами.

| Время, мс | Что происходит |
|---|---|
| 0–850 | **Карта выезжает.** Старт: `translateY 60`, `scale 0.9`, `rotate −2°`, `opacity 0`. Перелёт к ~560: `translateY −6`, `scale 1.02`, `rotate 0.5°`, `opacity 1`. К 850 — покой. Кривая `bezier(0.2, 1.2, 0.3, 1)` или пружина `damping ≈ 14`, `stiffness ≈ 160` |
| 560 | Вибрация `Haptics.impactAsync(Medium)`: карта «легла» |
| 700 / 950 / 1200 | **Искры** — три ромба вокруг карты (позиции ниже), каждая живёт 1400 мс: `opacity 0 → 1` (к 25 %) → `0`, `translateY 0 → −14` (к 25 %) → `−60`, `scale 0.4 → 1 → 0.6` |
| 900–2300 | **Блик.** Полоса шириной 34 % карты и высотой 180 %, повёрнута на 20°, верх −40 %. Заливка — горизонтальный градиент: 0 % `rgba(sheen,0)`, 45 % `rgba(sheen,0.18)`, 50 % `rgba(255,255,255,0.28)`, 55 % `rgba(sheen,0.18)`, 100 % `rgba(sheen,0)`. Сдвиг по X от −160 % до +260 % своей ширины, ease-in-out. Обрезается внутренней частью карты |
| 1000–1600 | **Нижний блок** проявляется: `opacity 0 → 1`, `translateY 12 → 0` |
| после 2300 | Покой. Работает наклон (раздел 6) |

Искры (относительно контейнера карты):

| № | Позиция | Размер | Цвет | Форма |
|---|---|---|---|---|
| 1 | слева 14, сверху 120 | 10 | первый цвет `spark` | ромб (квадрат под 45°) |
| 2 | справа 8, сверху 70 | 8 | второй цвет `spark` | квадрат |
| 3 | справа 24, сверху 300 | 6 | первый цвет `spark` | квадрат |

**Уменьшение движения** (системная настройка или настройка «Анимации повышения уровня» выключена): всё сразу в конечном состоянии, без блика, искр и наклона; смена стиля — простая смена без поворота.

## 6. Наклон карты (голографический эффект)

- `expo-sensors`, `DeviceMotion`, интервал 33 мс. Работает только когда экран открыт и приложение активно, и только после окончания анимации появления.
- При открытии запоминается исходное положение телефона, отклонение считается от него, ±20° максимум.
- Сглаживание: на каждом шаге `current += (target − current) × 0.15`.
- Карта: `rotateX = −β × 0.3`, `rotateY = γ × 0.3`, каждое ограничено ±6°, перспектива 1000.
- Блик в покое: та же полоса, но с прозрачностью 60 % от обычной. Её положение по X следует за наклоном: γ от −20° до +20° соответствует сдвигу от −60 % до +160 %.
- Если технически возможно (раздел 8), угол градиента рамки-фольги смещается: `150° ± 15°` вслед за γ.
- При перетаскивании пальцем (свайп стиля) наклон ставится на паузу.

## 7. Содержимое карты

Все функции чистые, с тестами.

- `pickCardStats(diff, sheet) → Stat[3]` — три самых важных **изменения** по приоритету из `keyNumbersPreview` (документация, раздел 7.2). Если изменений меньше трёх, добираются ключевые числа без изменения: КЗ, хиты, бонус атаки основным оружием (изменение «—»).
  - Подпись прописными, до 11 символов. Длинные — по словарю сокращений: «СКР. АТАКА», «ПАСС. ВОСПР.», «СЛ ЗАКЛ.».
  - Значение: число со знаком для бонусов (`+7`), без знака для хитов и КЗ (`46`), кубики как есть (`4к6`).
  - Изменение: `+8`, `+3`, для кубиков `+1к6`.
- `cardSubtitle(character) → string`: «Вид · Класс · Подкласс»; при мультиклассе «Вид · Плут 5 / Волшебник 1». Одна строка с многоточием.
- `cardUnlocked(deck, choices) → string`: названия новых умений и сделанных выборов через запятую: «Компетентность: Восприятие и Акробатика». До 2 строк с многоточием. На 20-м уровне — название умения вершины.
- `cardNext(character) → string | null`: «Дальше, на 7-м: Увёртливость, Надёжный талант». На 20-м уровне — `null`, строки нет.
- `cardFooter(campaign, session, date) → string`: «Тени Солёной Гавани · сессия 12 · 06.11.2026». Без кампании — только дата. Дата `ДД.ММ.ГГГГ`.
- `defaultCardStyle(character) → CardStyle` — по разделу 4.4.
- **Знак бренда** — константа `BRAND_MARK = { first: 'КУБИ', second: 'КОД' }` в одном месте. Название приложения ещё выбирается, после выбора меняется только она.
- **Портрет:** фото персонажа, если есть (обрезка по кругу), иначе первая буква имени.
- **Доступность:** у карты одна подпись для экранного диктора: «Карта героя: Ирма Вейл, 6-й уровень. Хиты 46, плюс 8. Восприятие плюс 7, плюс 3. …». Декоративные слои скрыты от диктора.

## 8. Как рисовать

Рекомендуемый вариант:
- **Декоративные слои** (рамка-фольга, внутренний радиальный фон, кольцо портрета с конической заливкой, свечение, блик) — `@shopify/react-native-skia` (работает в Expo Go): `LinearGradient`, `RadialGradient`, `SweepGradient`, `Shadow` / `Blur`.
- **Текст и медальоны** — обычные компоненты React Native поверх холста Skia, шрифты проекта.
- **Анимации** — `react-native-reanimated`; значения передаются в Skia напрямую.

Запасной вариант без Skia: `expo-linear-gradient` для линейных градиентов, `react-native-svg` (`RadialGradient`) для радиальных. Кольцо портрета — SVG-окружность с двумя линейными градиентами, как приближение конической заливки. Свечение — круг с радиальным градиентом, **не** тень: на Android цветные тени не работают.

## 9. Картинки для «Поделиться»

Кнопка «Поделиться» открывает шторку с двумя вариантами: «Пост 4:5» и «Сторис 9:16». Затем системное меню отправки (`expo-sharing`). Картинка рендерится в невидимом контейнере фиксированного размера и снимается `react-native-view-shot` с нужной шириной в пикселях. Анимаций в картинке нет: блик и искры в покое, наклона нет.

### 9.1 Пост 4:5 — 1080 × 1350 px
- Базовая сцена 390 × 487,5 pt, снимок с шириной 1080 px (масштаб ×2,77).
- Фон — `screenBg` стиля, центр (50 %, 45 %).
- Карта шириной 350 по центру, сверху и снизу одинаковые поля. Если не помещается по высоте — масштаб карты уменьшается целиком.
- Искры в статичных позициях (как в 9.2), без шапки и кнопок.

### 9.2 Сторис 9:16 — 1080 × 1920 px (`u5b-storis.png`)
- Базовая сцена 390 × 693 pt, снимок с шириной 1080 px.
