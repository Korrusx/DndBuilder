  `tr()`. Тексты из `data-pipeline/extra` и `srd/` тоже двуязычные. Тест не пропускает кириллицу в английских полях.

- **Мастер создания**: возврат к прошлым шагам (кнопка «Назад», нажимаемая полоска прогресса).
- **Создание по правилам 2024**:
  - языки от класса (воровской жаргон + 1 язык, друидический);
  - «Чудотворец» и «Волхв»: + МДР к навыкам;
  - заклинания вида (родословные эльфа и гнома, наследие тифлинга, «Несущий свет»);
  - воззвания колдуна и метамагия чародея (`data-pipeline/srd/class-options.json`);
  - книга волшебника;
  - Друидический — редкий язык.
- **Бой**:
  - стили «Стрельба», «Сражение большим оружием», «Сражение двумя оружиями»;
  - урон двумя руками у универсального оружия;
  - дополнительная атака лёгким оружием;
  - ярость (в том числе с фехтовальным оружием);
  - магическое оружие +1…+3;
  - божественная кара (с бесплатной раз до долгого отдыха).
- **Урон заклинаний**:
  - кнопки «Атака» / «Урон» / «Лечение» на «Магии»;
  - рост по кругам и уровням читается из текста SRD;
  - 21 заклинание без данных API добавлено в `data-pipeline/srd/spell-damage.json`.
- **Режим игры**: карточка «Владения и языки» на «Навыках», плитка пассивного восприятия на «Листе».
- **Мультикласс**: расчёты, повышение уровня с выбором класса, интерфейс (см. `docs/multiclass.md`).

## Осталось / идеи

- **Редакция 2014 (SRD 5.1)** — в работе, сделаны этапы А1 (справочник и поле `edition`), Б (расчёты), В (мастер создания) и Г (игра, повышение уровня, PDF); осталось А2 (механика PHB 2014) и перевод SRD 5.1, дальше — `docs/edition-2014.md`.

- **Хоумбрю** — свои предметы и черты (последний большой этап из плана).
- **Мистический рыцарь / Мистический ловкач** (PHB): у подклассов нет заклинаний; потом — «треть уровня» в ячейках мультикласса.
- **Сверка механики с книгами** (может сделать только пользователь): 7 новых видов и подклассы PHB писались по памяти.
  Меньше всего уверенности в Кхораваре.
- **Термин**: в переводе SRD у чародея встречаются «очки» и «единицы» чародейства. Нужно выбрать одно.
- Из плана CLAUDE.md: обновление справочника по сети, синхронизация.

## Известные упрощения

- **Воззвания:**
  - повторяемые («Мучительный взрыв» и др.) можно взять только один раз;
  - «Мучительный взрыв» прибавляет ХАР только к «Мистическому заряду»;
  - атака Харизмой у «Договора клинка» и черта от «Уроков Первых» не считаются.
- **Повышение уровня:** замена одного воззвания, варианта метамагии или заклинания не ограничена одной.
- **Мультикласс:** «Дополнительная атака» от двух классов — только текстом, число атак приложение не считает.
- **Урон без кнопки или упрощённый:**
  - «Небесный огонь» и другие с двумя видами урона — только основная часть;
  - у призывов, «Истинного удара» и «Дубинки» кнопки урона нет;
  - урон дротиков «Волшебной стрелы» бросается одной суммой.
- **Навыки:** уже имеющийся навык выбрать повторно нельзя. Решено оставить так.

## Полезно знать при работе

- **Справочник:**
  - пересборка — `npm run data:build`, после неё на телефоне `npx expo start -c`;
  - перевод лежит в `data-pipeline/translations/*.csv`. Русский текст из `extra/` и `srd/` попадает туда черновиком
    только если строки ещё нет. Чтобы обновить уже записанный перевод, удалить его строки из CSV и пересобрать.
- **Источник SRD 5.2.1** — PDF `https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf`
  (текст достаётся `pdftotext`). Данные API (`data-pipeline/raw`) неполные: где чего-то нет, добавлено в `data-pipeline/srd/`.
- **Тесты:** jest не может импортировать `@/shared/i18n` (тянет expo-sqlite), поэтому чистые функции и тесты
  импортируют из `@/shared/i18n/model`.
- **Prettier не запускать:** конфигурации нет, он меняет кавычки.
- **Выборы персонажа** хранятся в `choices` по ключам из `CHOICE_KEYS`. Префиксы `class.` / `feature.` / `trait.`
  сбрасываются при смене класса или вида. Выборы уровня помечаются **общим** уровнем персонажа (`lvl<N>`).
