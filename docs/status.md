# Состояние проекта

Обновлено 07.11.2026, версия приложения 1.6.0 (история — `CHANGELOG.md` и `src/shared/config/changelog.ts`). Подробно о мультиклассе — `docs/multiclass.md`, о редакции 2014 — `docs/edition-2014.md`, о хронике кампании — `docs/chronicle.md`, о повышении уровня — `docs/features/level-up.md`.

## Сделано (сверх этапов 1–8 из CLAUDE.md)

- **Два языка** (i18next): интерфейс в `src/shared/i18n/locales/{ru,en}.json`, тексты справочника `{ en, ru }` через
  `localizeText()`. Тексты из `data-pipeline/extra` и `srd/` тоже двуязычные. Тест не пропускает кириллицу в английских полях.
- **Виды не из SRD**: Аасимар, Дампир, Калаштар, Кованый, Кхоравар, Ченджлинг, Шифтер (`data-pipeline/extra/species.json`).
- **Иконки** game-icons.net (CC BY 3.0) на плитках классов и видов: `src/shared/config/gameIcons.ts`, компонент `GameIcon`.
- **Мастер создания**: возврат к прошлым шагам (кнопка «Назад», нажимаемая полоска прогресса).
- **Создание по правилам 2024**:
  - языки от класса (воровской жаргон + 1 язык, друидический);
  - «Чудотворец» и «Волхв»: + МДР к навыкам;
  - заклинания вида (родословные эльфа и гнома, наследие тифлинга, «Несущий свет»);
  - воззвания колдуна и метамагия чародея (`data-pipeline/srd/class-options.json`);
  - книга волшебника;
  - Друидический — редкий язык.
- **Бой**:
  - стили «Стрельба», «Сражение большим оружием», «Сражение двумя оружиями»;
  - урон двумя руками у универсального оружия;
  - дополнительная атака лёгким оружием;
  - ярость (в том числе с фехтовальным оружием);
  - магическое оружие +1…+3;
  - божественная кара (с бесплатной раз до долгого отдыха).
- **Урон заклинаний**:
  - кнопки «Атака» / «Урон» / «Лечение» на «Магии»;
  - рост по кругам и уровням читается из текста SRD;
  - 21 заклинание без данных API добавлено в `data-pipeline/srd/spell-damage.json`.
- **Режим игры**: карточка «Владения и языки» на «Навыках», плитка пассивного восприятия на «Листе».
- **Мультикласс**: расчёты, повышение уровня с выбором класса, интерфейс (см. `docs/multiclass.md`).
- **3D-броски** (прототип `dice-table.html`): three.js + cannon-es в WebView, встроены в сборку
  (`data-pipeline/dice/scene.html` → `npm run dice:scene` → `src/features/roll-dice/config/diceScene.generated.ts`).
  Числа выбирает приложение (expo-crypto), сцена подгоняет грани и сообщает «остановились», затем итог и вибрация
  (expo-haptics). В «О приложении» → «Броски»: 3D-стол / простой бросок, анимация, вид кубиков и стола.
  Если WebGL не запустился, панель сама переходит на простой бросок. На столе к20 (проверки, спасброски, атаки,
  атаки заклинаниями) и кости урона/лечения к4–к12 (оружие, заклинания, скрытая атака, кара). Лоток с деревянными
  бортиками; при многих костях они мельче, больше 20 костей — простой показ. Стук костей и звуки естественных 20 и 1
  (`npm run dice:sounds`). Тест `config/__tests__/diceScene.test.ts` сверяет собранную сцену с исходниками.
- **Вещи** (`src/pages/play-items/`): кукла со слотами по телу (голова, плечи, тело, руки, кольца, оружие в руках…),
  выбор предмета для слота из рюкзака, двуручное оружие занимает обе руки, рюкзак в шторке, удаление с подтверждением,
  монеты. Счётчик «Настройка N/3» с пояснением по нажатию: больше 3 предметов, требующих настройки, надеть нельзя.
- **Хоумбрю предметы** (`src/features/homebrew-equipment/`, экран `homebrew-equipment`, таблица `homebrew_equipment`):
  снаряжение, оружие (кость и вид урона), броня (КЗ, тип, помеха Скрытности); магический бонус и дополнительный урон.
- **Эффекты предметов** (`ItemEffect` в `shared/content/types.ts`, применяются в `computeSheet`): бонус к КЗ,
  спасброскам, скорости, характеристикам (в том числе «установить значение»), навыкам, сопротивления. Магический
  бонус брони и щита идёт в КЗ, дополнительный урон — в атаку. **У магических предметов справочника эффекты пока
  не заполнены** — работают только бонус и урон своих предметов.
- **История обновлений** в «О приложении» (3 последние версии, остальные по кнопке) и баннер «Что нового» на экране
  персонажей при первом запуске новой версии.
- **Expo SDK 58** (react-native 0.88, react-native-webview 14, expo-router 58).

- **Хроника кампании** (`docs/chronicle.md`): летопись сессий с автособытиями, записи с @упоминаниями и фото,
  карточки людей, мест, фракций и квестов, личная линия со счётчиком и «Внести из кошелька», «В прошлый раз…»,
  «Зал героев», экспорт и импорт хроники; портреты карточек в списках «Люди» и «Места».
- **Повышение уровня «Ритуал → Колода → Итог»** (`docs/features/level-up.md`; страница `src/pages/level-up`,
  логика и компоненты `src/features/level-up`). Расчёты уровня не менялись — новая подача:
  - **ритуал** (`RitualPhase`): кольцо уровня со звуком, «Вас ждут N новинок и M выборов», «Открыть новинки» и
    «Взять уровень в другом классе» (число доступных классов, у недоступных причина — `multiclassShortfall`);
    нажатие до удара (1550 мс) пропускает анимацию;
  - **переход**: кольцо перелетает в значок уровня в шапке колоды (`FlyingRing`, положения через `measureInWindow`),
    карты раздаются из кольца (`DealIn`);
  - **колода** (`CardsStep`): лента квадратиками, счётчик «Открыто 1 из 2 · хиты не брошены · выборов 0 из 1»,
    карты в трёх состояниях (рубашка / свёрнута / развёрнута), «Открыть все», «Дальше» ведёт к первой
    незавершённой карте, строка «Без изменений»;
  - **карта хитов** — первая в колоде (`HpCard`, логика броска — `useHpRoll`): 3D-стол поверх экрана, среднее,
    свой кубик (сетка 1…кость), встряхивание; настройки «Разрешить переброс хитов» (теперь включена по умолчанию)
    и «Бросаю свои кубики»;
  - метка «N атаки» у «Дополнительной атаки» — поле `attacks` в `data-pipeline/level-meta.json`;
  - продолжение отложенного повышения открывает сразу колоду (метка `deck:opened` в `PendingLevelUp.revealed`).
  Старые экраны «Новый уровень», «Хиты» и макеты `design/level-up/` удалены.

## Осталось / идеи

- **Редакция 2014 (SRD 5.1)** — сделаны все этапы и перевод справочника; осталось сверить механику PHB 2014 с книгой
  (`docs/edition-2014.md`).
- **Эффекты магических предметов справочника** — заполнить `effects` (кольцо защиты, перчатки силы огра, плащ защиты…);
  в форме хоумбрю — остальные эффекты, кроме бонуса и урона.
- **Хоумбрю** — свои черты, заклинания, виды, классы (сделаны только предметы).
- **Мистический рыцарь / Мистический ловкач** (PHB): у подклассов нет заклинаний; потом — «треть уровня» в ячейках мультикласса.
- **Сверка механики с книгами** (может сделать только пользователь): 7 новых видов и подклассы PHB писались по памяти.
  Меньше всего уверенности в Кхораваре.
- **Термин**: в переводе SRD у чародея встречаются «очки» и «единицы» чародейства. Нужно выбрать одно.
- Из плана CLAUDE.md: обновление справочника по сети, синхронизация.
- **Хроника:** доска связей (Х6), итог боя из режима «Мой ход» (режима пока нет), хроника на главной панели,
  удаление осиротевших фото после замены кампании из файла.

## Известные упрощения

- **Воззвания:**
  - повторяемые («Мучительный взрыв» и др.) можно взять только один раз;
  - «Мучительный взрыв» прибавляет ХАР только к «Мистическому заряду»;
  - атака Харизмой у «Договора клинка» и черта от «Уроков Первых» не считаются.
- **Повышение уровня:**
  - замена одного воззвания, варианта метамагии или заклинания не ограничена одной;
  - отложили на ритуале, ничего не открыв, — при продолжении ритуал покажется снова;
  - кнопки «Сбросить повышение» сейчас нет (была на старом первом экране) — нужно решить, где её поставить;
  - на плитке ленты название, которое не помещается без разрыва слова, заменяется типом карты («Умение»,
    «Выбор»); короткие формы частых умений — словарь `levelUpDeck.screen.shortTitles` в `locales/*.json`;
  - в шапке карты хитов «КОСТЬ К8», а не «КОСТЬ ПАЛАДИНА»: родительного падежа у названий классов в справочнике нет.
- **Мультикласс:** «Дополнительная атака» от двух классов — только текстом, число атак приложение не считает.
- **Урон без кнопки или упрощённый:**
  - «Небесный огонь» и другие с двумя видами урона — только основная часть;
  - у призывов, «Истинного удара» и «Дубинки» кнопки урона нет;
  - урон дротиков «Волшебной стрелы» бросается одной суммой.
- **Навыки:** уже имеющийся навык выбрать повторно нельзя. Решено оставить так.

## Полезно знать при работе

- **Сборка APK:** `npx eas-cli build -p android --profile preview` (вход — `npx eas-cli login`; пакет называется
  `eas-cli`, не `eas`). Версия берётся из `app.json`.
- **Справочник:**
  - пересборка — `npm run data:build`, после неё на телефоне `npx expo start -c`;
  - перевод лежит в `data-pipeline/translations/*.csv`. Русский текст из `extra/` и `srd/` попадает туда черновиком
    только если строки ещё нет. Чтобы обновить уже записанный перевод, удалить его строки из CSV и пересобрать.
- **Источник SRD 5.2.1** — PDF `https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf`
  (текст достаётся `pdftotext`). Данные API (`data-pipeline/raw`) неполные: где чего-то нет, добавлено в `data-pipeline/srd/`.
- **Тесты:** jest не может импортировать `@/shared/i18n` (тянет expo-sqlite), поэтому чистые функции и тесты
  импортируют из `@/shared/i18n/model`.
- **Стиль кода:** ESLint + Prettier (`.prettierrc`). Исправить: `npx eslint src/ --fix`, потом `npm run format`;
  проверить: `npm run lint` (ошибок нет, 13 предупреждений о неиспользуемых импортах).
- **Сгенерированные файлы** (`*.generated.ts`) не менять массовой заменой по проекту: так сломалась 3D-сцена
  при переименовании `tr` → `localizeText`. Пересборка — `npm run dice:scene`.
- **Скрытые экраны в вкладках** (редактирование, повышение уровня) — через `HIDDEN_TAB`
  (`src/widgets/play-tabs/config/hiddenTab.ts`), не `href: null`: с Expo Router 58 с такого экрана сразу
  перекидывает на первую вкладку.
- **Выборы персонажа** хранятся в `choices` по ключам из `CHOICE_KEYS`. Префиксы `class.` / `feature.` / `trait.`
  сбрасываются при смене класса или вида. Выборы уровня помечаются **общим** уровнем персонажа (`lvl<N>`).
