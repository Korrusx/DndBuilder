# Хроника кампании

Версия 1.5.0. Макеты — `design/Х1…Х6`. Доска связей (Х6) не сделана, данные для неё есть (`entity_links`).

## Данные (миграция 5)

Кампания хранится отдельно от персонажа, персонажи прикрепляются к ней (`campaign_characters`: `active` / `fallen` /
`retired`, эпитафия). Таблицы: `campaigns`, `campaign_characters`, `sessions`, `entries` (заметки и автособытия),
`entities` (люди, места, фракции, квесты; `role` — короткая подпись, `place_id`, `personal`), `quest_steps`,
`quest_counters`, `entity_links`, `photos` (JPEG в base64: в Expo Go надёжнее файлов и сразу попадает в экспорт).
У всех строк есть `updated_at` — задел для синхронизации.

Старое поле `Character.campaign` перенесено в кампании один раз при запуске (`linkLegacyCampaigns`, флаг
`meta.legacyCampaignsLinked`). Поле не удалено: оно видно на карточке персонажа и обновляется при «Начать хронику».

Упоминание в тексте записи — токен `@[Борис](e:<id>)`. Показывается всегда текущее имя карточки. В редакторе текст
хранится как «@Борис» плюс диапазоны (`MentionDoc`): правка внутри упоминания превращает его в обычный текст.

## Где что

- `entities/campaign` — модель (упоминания, поиск, склейка событий, квесты, давность, сводка, летопись по блокам,
  файл хроники), работа с базой, запись событий (`recordEvent`) и настройки журнала (`meta.chronicleSettings`).
- `shared/lib/play-events` — шина событий режима игры. Шлют: `CharacterProvider.update()` (сравнение «до/после»:
  0 хитов, стабилизация, смерть, уровень, вещи, монеты; `{ journal: false }` — не записывать), `D20Sheet`
  (натуральные 20 и 1), отдых.
- `features/chronicle-journal` — подписка на шину (`startJournal`), монеты копятся 3 секунды; строка «куда пишутся
  события» на «Листе»; раздел «О приложении → Хроника».
- `features/join-campaign` — «Начать хронику». `features/pay-quest` — «Внести из кошелька» (`spendCoins` с разменом).
- `widgets/quest-board` — вкладка «Квесты». Страницы: `campaign` (Х1), `campaign-entry` (Х2), `campaign-entity`
  (Х3 и карточка квеста), `campaign-recap` (Х5).
- Обмен: файл `.geroy-chronicle.json` (`shareChronicle`); хроника может ехать внутри `.dnd.json` персонажа
  (поле `chronicles`), при импорте id героев переназначаются на новые.

## Что не пишется в летопись

- Итог боя: нет режима «Мой ход». Событие `combat` (раунды, урон, получено) и его текст готовы — достаточно
  вызвать `emitPlayEvent({ type: 'combat', rounds, dealt, taken })`.
- Обычные броски и обычный урон — по задумке; только натуральные 20/1 и 0 хитов.
- События героя из «Зала героев» не пишутся.
