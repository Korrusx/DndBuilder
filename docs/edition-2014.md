# Редакция 2014 (SRD 5.1)

Персонаж можно создать по правилам 2014 года. Редакция выбирается при создании и потом не меняется
(`Character.edition: '2014' | '2024'`; у персонажей, сохранённых раньше, поля нет — они по 2024).

## Решения, принятые с пользователем

1. **Объём**: SRD 5.1 + механика Player's Handbook 2014 (расы, подрасы, предыстории, черты, подклассы) — так же,
   как для 2024: механика в `data-pipeline/extra-2014/`, описания своими словами, коротко.
2. **Справочник отдельный**: `assets/content/content-2014.json`, та же структура (`src/shared/content/types.ts`),
   поля только для 2014 помечены там «2014». В приложении — `contentFor(edition)`; справочник 2014 загружается
   при первом обращении.

## Этапы

- **А1 — данные SRD 5.1 и поле редакции** (сделано).
- **А2 — механика PHB 2014** в `extra-2014/` (в работе): А2.1 происхождение, А2.2 черты, А2.3 подклассы — сделано.
- **Б — расчёты** (сделано) с тестами (контрольный персонаж 2014): прибавки расы, известные / подготовленные заклинания
  (2014: характеристика + уровень), долгий отдых — половина костей хитов, истощение 6 уровней, подкласс с 1–3 уровня,
  без приёмов оружия и черт происхождения.
- **В — мастер создания** (сделано): выбор редакции, раса вместо вида с прибавками, предыстория без прибавок и черты.
- **Г — игра, отдых, повышение уровня, PDF** (сделано).

## А1 — что сделано

- `npm run data:fetch:2014` — сырые данные `/api/2014` в `data-pipeline/raw-2014/` (расы и подрасы — `races`, `subraces`).
- `npm run data:build:2014` — `data-pipeline/build-2014.ts` собирает `content-2014.json`; общие части сборки обеих
  редакций — в `data-pipeline/common.ts` (`build.ts` — только 2024, результат 2024 не изменился).
- Перевод — `data-pipeline/translations-2014/*.csv` (тот же формат). Если ключ и английский текст совпадают с 2024,
  перевод берётся из `translations/`; совпадающие названия — черновиком. Остальное пока без перевода
  (`missing-translations-2014.txt`).
- id инструментов приведены к виду 2024 (`thieves-tools` → `tool-thieves-tools`, `dice-set` → `tool-dice`),
  чтобы код приложения узнавал одни и те же владения.
- Что в справочнике 2014 по-другому:
  - раса: `abilityBonuses`, `abilityBonusChoice` (полуэльф), `languages`, `languageChoice`; подраса: `abilityBonuses`;
  - особенность: `proficiencies`, `languageChoice`, `spellChoice` (заговор высшего эльфа), `subtraits` / `parent` /
    `damageType` (наследие драконов);
  - предыстория: `abilities: []`, без `featId`, `languageChoice`, `feature` (умение предыстории);
  - класс: `spellcasting.preparation` (`known` / `prepared`), в таблице уровней `known`, `prepared` = 0 (считается формулой);
    снаряжение без выбора — первым «выбором» из одного набора;
  - умение: `parent` (воззвание, стиль боя, метамагия — варианты умения), `optionChoice`, `expertiseChoice`;
  - подкласс: `spells` (заклинания домена / клятвы с уровня), `summary` — первое предложение описания;
  - приёмов оружия нет, `resources` и `classOptions` пока пустые.
- Импорт файла проверяет персонажа по справочнику его редакции.
- Тесты: `src/shared/content/__tests__/edition2014.test.ts`.

## Б — что сделано

Код: `src/entities/character/model/` (`sheet.ts`, `build.ts`, `spells.ts`, `rest.ts`, `play.ts`), `config/effects.ts`.
Функции со справочником смотрят на `content.edition`; без справочника (отдых, истощение) — параметр `edition`,
по умолчанию 2024, так что расчёты 2024 не изменились.

- **Характеристики** (`finalAbilityScores(c, content)`): в 2014 — прибавки расы и подрасы, прибавки на выбор
  (полуэльф) в `choices['trait.abilityBonus']`; бонусы предыстории не действуют.
- **Владения от особенностей расы** (`Trait.proficiencies`): «Острые чувства», «Обучение эльфийскому оружию» и т.п.
- **Варианты умений и особенностей** — выбранный вариант (`choices['feature.<id>']`, `choices['trait.<id>.option']`)
  попадает в умения персонажа со своими эффектами: боевой стиль, наследие драконов.
- **Эффекты 2014** — `EFFECTS_2014` (перекрывают общие по тому же id): «Бдительность» +5 к инициативе, боевые стили,
  «Движение без доспехов» монаха, «Драконья устойчивость» (13 + ЛОВ, +1 хит за уровень).
- **Заклинания** (`spellLimits`): известные — по таблице (лежат в тех же списках, что подготовленные);
  подготовленные — мод. + уровень (паладин — мод. + половина уровня), не меньше 1.
  Заклинания подкласса — `sheet.subclassSpells` (всегда подготовлены, в лимит не входят).
- **Ячейки мультикласса**: половина уровня паладина и следопыта — вниз (2024 — вверх).
- **Долгий отдых**: половина костей хитов (не меньше одной), сначала самые крупные.
- **Истощение**: `exhaustionPenalty` = 0, `speedWithExhaustion`, `maxHpWithExhaustion`, `exhaustionEffects2014`
  (помехи на проверки / атаки и спасброски, смерть на 6-м).
- **Компетентность** плута 2014 и **языки расы** — в `expertiseCount`, `knownLanguages`.
- Тесты: `irma2014.test.ts` (контрольный пример ниже), `rules2014.test.ts`.

Контрольный пример — Ирма 2014 (`irma2014Level1`, `irma2014Level5`): плут 1, легконогий полурослик, «Преступник»;
база СИЛ 8, ЛОВ 15, ТЕЛ 14, ИНТ 13, МДР 12, ХАР 10; раса ЛОВ +2, подраса ХАР +1. Итог: ЛОВ 17 (+3), ИНТ 13 (+1),
ХАР 11. Хиты 10, КЗ 14, инициатива +3 (черты нет), скорость 25, пасс. восприятие 13; спасброски ЛОВ +5, ИНТ +3;
Скрытность и Ловкость рук +7, Акробатика +5, Анализ +3, Восприятие +3, Обман +2; атаки +5, урон 1к6+3 / 1к4+3 / 1к6+3.
5-й уровень (ЛОВ +1, ТЕЛ +1 на 4-м): ЛОВ 18, хиты 38, БМ +3, инициатива +4, КЗ 15, скрытая атака 3к6.
«Преступника» нет в SRD 5.1 — в тесте он задан прямо в файле, после А2 возьмётся из `extra-2014`.

## В — что сделано

- **Активная редакция** (`src/shared/content/content.ts`): `content` и `byId` — справочник активной редакции.
  `useActiveEdition(edition)` в DraftProvider и CharacterProvider переключает его на редакцию персонажа (сразу
  при отрисовке) и возвращает 2024 при закрытии. Экраны с несколькими персонажами (список, карточка, `safeSheet`,
  импорт) берут справочник каждого явно — `contentFor(c.edition)`.
- **Шаг 1**: переключатель «D&D 2024 / D&D 2014» (`setEdition` — черновик заново, имя остаётся); подкласс 1-го уровня
  (жрец, чародей, колдун 2014 — `subclassLevel`, `setSubclass`).
- **Шаг 2**: «Раса» / «Подраса» с прибавками и языками; умение предыстории; прибавки полуэльфа на выбор
  (`trait.abilityBonus`); вариант особенности — наследие драконов (`trait.<id>.option`); заговор высшего эльфа
  (`trait.<id>.spell`, творится ИНТ — в заклинаниях вида).
- **Шаг 3**: столбец «Бонус» — прибавки расы; вместо бонусов предыстории — подсказка.
- **Шаг 4**: варианты умений 1-го уровня (`featureChoices`: боевой стиль, драконий предок); владения от расы среди
  «уже есть»; языки — `languageChoiceCount` / `languageChoiceOptions` (раса + особенности + предыстория, любые).
- **Шаг 5**: снаряжение из нескольких выборов (`equipmentChoices`, `chosenEquipmentOption`; ключи
  `equip.<источник>.<номер>` и `…pick.<i>`, первый выбор — прежние ключи 2024); вариант без альтернативы выбран сразу;
  «два воинских оружия» — два предмета. Известные заклинания вместо подготовленных у бардов и др.;
  заклинания подкласса — подсказкой.
- Карточка в списке — плашка с редакцией (2024 / 2014) рядом с именем.
- Тесты: `features/create-character/model/__tests__/creation2014.test.ts`.

## Г — что сделано

- **Ресурсы умений 2014** — `data-pipeline/srd-2014/resources.json`: ярость (только долгий отдых), бардовское
  вдохновение (к6…к12, с «Источника вдохновения» — короткий отдых), божественный канал, дикий облик, второе дыхание,
  всплеск действий, несгибаемость, ки, божественное чувство (1 + ХАР — формула `ability` с `plus`), наложение рук,
  единицы чародейства, таинственный арканум, магическое восстановление, оружие дыхания и др.
- **«Увеличение характеристик»** в справочнике 2014 — черта `ability-score-improvement` (в SRD 5.1 это умение класса).
- **Повышение уровня**: подкласс на уровне первого умения подкласса (волшебник — 2, воин — 3); «Увеличение
  характеристик» по id умений 2014; компетентность от `expertiseChoice`; варианты умений нового уровня
  (`plan.optionChoices`: боевой стиль паладина и следопыта, договор, метамагия, воззвания — всего по столбцу
  `invocations_known`). Таблицы умений 2024 (`FEAT_FEATURES`, `FEATURE_OPTIONS`, `FEATURE_LANGUAGES`, `*_GRANTS`) для
  2014 не применяются — часть id совпадает, а выбор устроен иначе.
- **Режим игры**: долгий отдых — половина костей хитов; истощение — помеха вместо −2 (`d20Parts` смотрит активную
  редакцию), скорость и подсказки по уровням, максимум хитов вдвое меньше с 4-го уровня (в `computeSheet`);
  «Магия»: «Известные» у бардов и др., «Всегда подготовлены (подкласс)».
- **PDF**: «Раса» и «Особенности расы», умение предыстории в блоке черт, заклинания подкласса в списке.
- **Ошибки таблиц API, исправленные по PDF SRD 5.1** (`CLASS_TABLE_FIXES` в `build-2014.ts`): воззвания колдуна
  (3 — с 5-го, 4 — с 7-го), метамагия чародея (4 — с 17-го), ярость варвара 20-го уровня (без ограничения).
  Сверены с PDF также таблицы барда, чародея, следопыта, монаха и варвара — совпадают.
- Тесты: `levelup2014.test.ts`, ресурсы и истощение в `rules2014.test.ts`, `d20Parts.test.ts`, PDF 2014 в `sheetHtml.test.ts`.

## А2.1 — происхождение (сделано)

- 12 предысторий PHB (`extra-2014/backgrounds.json`): навыки, инструменты, языки на выбор, снаряжение, умение.
- Подрасы: горный дварф, лесной эльф, тёмный эльф (дроу), коренастый полурослик, лесной гном; раса «Человек (вариант)»
  (+1 к двум, навык, черта, язык) — `extra-2014/species.json`.
- Заклинания расы по уровням (`Trait.spellLevels`): магия дроу, «Наследие Ада» тифлинга; характеристики — в
  `SPECIES_SPELL_FIXED_ABILITY`.
- Черта человека-варианта — тот же слот, что «Универсальность» 2024 (`versatile.feat`); если черта даёт +1 —
  `versatile.ability` (`Feat.abilityIncrease`). Условия черт на шаге 2 не проверяются (характеристики ещё не заданы).
- У предыстории 2014 нет черты — пустого слота черты больше нет (`originFeats`).
- Тесты: `phb2014-origins.test.ts`; Ирма 2014 теперь с настоящим «Преступником».

## А2.2 — черты (сделано)

- 41 черта PHB 2014 (`extra-2014/feats.json`): `abilityIncrease` (+1 к одной из списка), `proficiencies`,
  `proficiencyChoices` («Мастер оружия» — 4 вида оружия), `savingThrowFromIncrease` («Устойчивый»), условия
  (`prerequisites.proficiency` — «все доспехи» тоже подходят, `spellcasting`, характеристика 13).
- `featAbilityRule(featId, content)`: в 2014 прибавка из данных черты (у «Захвата» 2014 её нет).
- Эффекты (`EFFECTS_2014`): «Бдительный» +5 к инициативе, «Подвижный» +10 фт, «Наблюдательный» +5 к пассивному
  Восприятию, «Мастер средних доспехов» до +3 ЛОВ, «Крепкий» +2 хита за уровень. Ресурсы — `extra-2014/resources.json`
  («Везунчик», «Мастер боевых искусств»).
- «Посвящённый в магию» 2014: шесть классов, характеристика — класса (выбирается сама).
- Тесты: `features/level-up/model/__tests__/feats2014.test.ts`.

## А2.3 — подклассы (сделано)

- 28 подклассов PHB 2014 (`extra-2014/subclasses-1.json`, `subclasses-2.json`): умения по уровням, заклинания домена
  и клятвы (`spells`), расширенный список колдуна (`expandedSpells` — добавляется к вариантам в `preparableSpells`,

- Владения от умений (`Feature.proficiencies`, `proficiencyChoices`): домены бури, войны, природы, знаний, коллегия

  Выбор навыков от умения — при создании (1-й уровень) и при повышении уровня.
- Ресурсы подклассов (`extra-2014/resources.json`): кости превосходства, защитная вспышка, гнев бури, боевой жрец,
  знамение, фейское присутствие и др.
- Заклинаний PHB, которых нет в SRD 5.1, в списках подклассов нет: «Опутывающий удар», «Хватающая лоза»,
  «Волна разрушения», «Мантия крестоносца», «Призрачная сила», «Диссонирующий шёпот».

## Известное (решить на следующих этапах)

- Условия воззваний 2014 (уровень, договор, «Мистический заряд») не проверяются — показываются все.
- Помеху от истощения 2014 игрок включает в окне броска сам.
- Заклинания «Наследия Ада» тифлинга 2014 (по уровням) пока не добавлены — нет в данных API.
- Компетентность плута 2014 можно взять только в навыках (воровские инструменты — нельзя).
- Избранный враг и исследователь природы следопыта — только текстом.
- Черты 2014 без расчёта (только текст): +1 КЗ «Сражения двумя оружиями», к4 безоружного удара «Трактирного
  драчуна», пассивный Анализ «Наблюдательного», языки «Лингвиста» (добавить вручную в «Изменить»).
- Подклассы 2014 без расчёта (только текст): тотемы варвара, стихийные дисциплины монаха, приёмы мастера
  боевых искусств, спутник повелителя зверей; компетентность домена знаний и языки (добавить вручную);
  заговор домена природы. Мистический рыцарь и мистический ловкач — заклинания и ячейки не считаются.
- Короткое описание подкласса 2014 — первое предложение английского текста (до перевода).
- «Увеличение характеристик» 2014 хранится как черта `ability-score-improvement`, которой нет в справочнике 2014
  (только для названия на экране) — этап Г.
- «Сражение большим оружием» 2014 (переброс 1 и 2) и «Дуэлянт» не считаются.

- Избранный враг и исследователь природы (следопыт) — выбор врага / местности есть в API только текстом.
- Воззвания и метамагия 2014 лежат умениями с `parent`; для экрана выбора их, вероятно, стоит превратить в `classOptions`.
- Заклинания особенностей с уровнем («Наследие Ада» тифлинга) в данных API без уровней.
- Лечение без костей («Подмога», «Исцеление») — без кнопки.
